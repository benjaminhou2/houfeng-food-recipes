# 侯峰的美食

本仓库收集了来自抖音平台的美食制作教程，主要来源于 **笑笑的番茄** 和 **凤姐的菜** 等美食博主。

## 项目简介

- **用途**：记录和整理抖音短视频中的菜谱文案、制作步骤和所需材料
- **来源**：抖音（TikTok China）美食视频
- **格式**：Markdown 文档，每道菜独立一个文件
- **数量**：目前收录 16 道菜谱

## 文件格式说明

每个菜谱文件包含以下结构：
- **视频信息**：标题、作者、粉丝数、发布时间、点赞/评论/收藏/分享数据、视频链接、标签
- **AI 摘要**：视频内容的 AI 自动生成摘要
- **详细步骤**：按时间戳分段的制作步骤
- **所需材料汇总**：
  - **主料**：主要食材
  - **调料**：调味品和辅料

## 常用调料统计

覆盖全部菜谱的核心调料：
- **盐**、**生抽**、**蚝油**
- **小米辣**、**花椒粒**
- **花雕酒**、**白糖**
- **葱姜蒜**、**香菜**
